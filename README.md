# AWS-DVA-Learning

## Lambda 
AWS Lambda és un servei d’Amazon Web Services (AWS).
Permet executar codi sense haver de gestionar servidors.
El codi s’executa automàticament quan passa un esdeveniment.
Per exemple: pujar una imatge → Lambda la processa automàticament.
Només pagues pel temps que el teu codi està executant-se.
